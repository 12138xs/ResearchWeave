# A510 知识库功能范围

最后更新：2026-06-02。

A510 知识库是面向研究团队内部使用的研究工作台，服务于论文阅读、知识文档、复现实验、统一检索、质量治理和 AI 辅助研究。本仓库文档不记录真实服务器 IP、本地个人路径、成员信息、备份目录或运行期密钥；这些内容由私有运维环境维护。

当前系统版本：`v0.4.4`。

## 当前范围

| 项目 | 当前值 |
| --- | --- |
| 用户可见产品名 | A510知识库 |

## 核心功能

### 论文库

- 浏览论文列表和论文详情。
- 上传 PDF，并触发元数据抽取和任务记录。
- 支持 AI 粗读、AI 精读、问答和人工复核记录。
- 支持阅读状态、负责人、下一步和复现状态维护。
- 支持从论文详情创建关联复现实验项目。
- 读接口保留内部公开浏览；写接口要求登录。

### 知识文档

- 浏览、创建和编辑团队知识文档。
- 记录文档版本。
- 支持导入批次、候选文档审批和图片上传。
- 支持关键词和知识空间关联。

### 知识体系

- 管理知识空间、主题树、关键词和目录统计。
- 支持知识空间详情页，展示相关论文、文档、实验和方向关系。
- `library` 只负责分类法和聚合视图，不承载论文、文档或实验的具体业务逻辑。

### 实验与复现

- 新增实验项目和实验运行记录。
- 实验项目可以关联论文、文档或知识空间。
- 记录目标、protocol、代码仓库、运行参数、指标、产物和备注。
- 异步执行或环境检查通过 `TaskRecord` 展示。

### 统一检索

- 覆盖论文、文档和实验的数据库文本检索。
- 搜索结果展示类型、标题、摘要片段、关键词、更新时间和跳转入口。
- 搜索结果不得暴露服务器路径、storage path 或私有 PDF 路径。
- 第一版不启用复杂 RAG；索引重建通过异步任务触发。

### 质量治理

- 记录论文、文档、实验和搜索索引相关的质量问题。
- 支持维度、严重程度、状态、评分、证据和人工处理记录。
- 首页展示待复核摘要，详情页展示相关质量问题。
- 第一版只做提示和人工处理，不做复杂审批流。

### AI 研究助理

- 使用 scoped session 限定上下文范围。
- 支持文献比较、复现清单、方向 brief 和受限自由问答。
- 回答必须返回来源；上下文不足时必须说明限制。
- 长报告和批量任务通过 `TaskRecord` 异步执行。

### 方向地图

- 复用 `KnowledgeSpace` 作为方向节点。
- 支持知识空间之间的 related、prerequisite、extends、competes、application 关系。
- 第一版以列表和层级关系为主，不优先做复杂大图。

## 管理功能

- 登录、登出和当前用户信息。
- 任务队列展示异步处理状态。
- 系统设置页展示 release metadata、健康状态和运行信息。
- 版本信息通过 `release.json`、`backend/release.json`、`docs/CHANGELOG.md` 和 `/api/health/` 维护。

## UI/UX 状态

当前默认视觉方向为深色研究工作台。

- 默认主题：深色。
- 主视觉：蓝金配色；蓝色用于主行动、聚焦和信息层级，金色用于侧边栏高亮、重点提示和关键词。
- 侧边栏：按“核心功能、研究流程、管理治理”等分组整理；当前选中项使用金色文字和蓝色背景。
- 色系切换：位于右上角，不放在右下角悬浮。
- 框体：减少密集堆叠，使用留白、细边框、轻阴影和少量渐变表现层级。
- 关键词和标签：深色主题下必须保证可读性，不允许黑字贴在深色背景上。

详细 UI/UX 标准由本地工作区私有规范维护；GitHub 版文档只保留当前系统功能状态和实现事实。

## 模块边界

- `accounts/common/storage/tasks/ai` 是基础层。
- `library` 只管知识空间、关键词和分类法。
- `papers/documents/experiments` 是内容领域层。
- `search/quality/assistant/research_map` 是跨域编排层。
- 后端 `views` 只做 HTTP 编排；查询进入 `selectors`；写入和事务进入 `services`；Celery task 只调用 service。
- 前端新模块必须有 `src/api/<module>.ts` 和 `src/features/<module>/`，不得继续扩大 `LegacyApp.tsx`。

## 已知缺口

- 统一检索仍是数据库文本检索，尚未启用复杂 RAG 或 embedding 排序。
- 方向地图第一版偏列表化，尚未做成熟可视化图谱。
- 质量治理第一版以人工处理为主，尚未做复杂审批流。
- AI 研究助理仍需要继续强化来源展示、上下文不足提示和长报告任务体验。
- UI 还需要持续按新标准检查各页面，重点是统一检索、阅读与复现、实验详情和知识空间详情。
