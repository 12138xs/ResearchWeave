# ResearchWeave

ResearchWeave 是面向科研团队的知识工作台，用于把论文阅读、知识文档、复现实验、统一检索、质量治理和 AI 辅助研究放在同一个系统里。

它围绕科研流程组织知识：保存材料、核对出处、讨论问题、记录实验，再把可复用的结论沉淀回知识库。AI 助手从已有材料寻找依据，帮助比较工作、判断思路的条件与风险、设计下一步验证。

## 核心价值

- **论文读得懂**：集中管理论文元数据、PDF、AI 粗读、AI 精读、问答和人工复核。
- **实验接得上**：把论文与复现实验项目关联，记录目标、方案、运行参数、指标、产物和结论。
- **知识找得回**：通过统一检索同时找回论文、知识文档和实验记录。
- **结论更可信**：用质量治理模块记录元数据、AI 输出、复现、文档和索引中的待复核问题。
- **团队可协作**：通过知识空间、关键词、文档版本和任务队列共享研究上下文。

## 主要功能

### 研究材料与证据

- PDF 和 Markdown 材料入库、重复识别及原文件版本记录。
- 按页码或行号查看文本证据，定位到对应原文版本。
- 记录 PDF 提取内容的核对状态，保存带来源的研究卡片。
- 适合结合经过整理的文献卡、技术说明和实验记录逐步建设知识库；公式与复杂图表仍需核对原文。

### 论文库

- 论文列表、详情和 PDF 访问。
- 论文上传、元数据维护和关键词管理。
- AI 粗读、AI 精读、论文问答和人工复核。
- 阅读状态、负责人、下一步和复现状态记录。

### 知识文档

- 团队知识文档的创建、编辑和浏览。
- 文档版本记录。
- 文档导入候选、审批和知识空间归属。
- Markdown 与数学公式渲染。

### 知识体系

- 知识空间树。
- 关键词词表和主题聚合。
- 论文、文档和实验之间的主题关联。

### 实验与复现

- 复现实验项目。
- 实验运行记录。
- 参数、指标、产物和备注管理。
- 与论文、文档、知识空间的关联。

### 统一检索

- 跨论文、文档和实验的统一搜索。
- 按类型、关键词、知识空间和更新时间定位资料。
- 搜索结果提供跳转入口和摘要片段。
- 材料原文支持关键词召回和 AI 术语扩展、候选证据筛选。
- 当前采用文本检索方案，向量检索属于后续扩展方向。

### 质量治理

- 记录待复核问题。
- 标记问题严重程度和处理状态。
- 支持人工确认、解决、忽略和追踪。

### AI 研究助手

- 基于选定材料讨论研究进展、思路可行性与工作改进。
- 通过检索与独立证据复核组织回答，并提供可追溯引用。
- 保存会话，展示后台进度，支持取消与重试。
- 证据不足时说明缺口；模型建议需要结合原文与实验判断。

### 个人研究工作区

- 设置个人表达风格，手动维护、修改与停用研究背景记忆。
- 用模板记录问题、假设、代码与数据版本、观察和下一步。
- 将会话回答保存为研究记录，导出 Markdown。
- 整理独立的共享版本，把可复用成果交给团队。

### 方向地图

- 用知识空间表示研究方向节点。
- 维护方向之间的关联、前置、扩展、竞争和应用关系。
- 为后续研究路线梳理提供基础。

## 设计取向

ResearchWeave 偏向“科研工作台”而不是“展示型网站”。界面服务于高频查阅、比较、记录和复核，强调清晰的信息层级、克制但有质感的视觉风格，以及便于持续扩展的模块化结构。

## 技术栈

- 后端：Django、Django REST Framework、Celery
- 前端：React、TypeScript、Vite
- 数据：PostgreSQL、pgvector、Redis
- 部署：Docker Compose、Nginx
